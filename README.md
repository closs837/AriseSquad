# AriseSquad

Year-end project for ESGI's third year: a top-down action game built in Unity — the player
against wolves and a skeleton boss, with special attacks and dodges, plus the menus, saves
and level generation that hold it together. Modelling and animation were done in Blender;
the playable alpha build is under `Rendus/Alpha/` and the Unity sources under `Unity/`.

Built by a team of four over the school year. What we would have done next is listed in
`Todo.txt`.

## Contrôles (touches de déplacement)

Z/Q/S/D : touches de déplacement
SHIFT + Z/Q/S/D : courir dans la direction choisi
espace + Z/D/Q/D : esquives

Touches pour attaquer :

A : compétence 1
E : compétence 2
clic gauche : attaque normale

Menus :

tab : menu réanimation
p/echap : menu pause avec options/load/save/quitter/réssayer

Codes de triche :
c : perdre 10 pv
v : gagner 20 pv (si on a moins de 90 pv)

Pour faciliter les tests :
W : sauvegarder
X : charger
